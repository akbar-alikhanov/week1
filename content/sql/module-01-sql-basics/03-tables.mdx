## Theory

Таблица состоит из **столбцов** (каждый со своим именем и типом данных: текст, число, дата) и **строк** — отдельных записей. Например, таблица `products` имеет столбцы `product_id`, `name`, `category`, `price`, а каждая строка — конкретный товар.

## Example

```sql
SELECT * FROM products;
```

`*` означает «все столбцы» — запрос вернёт все строки таблицы products со всеми её столбцами.

## Common mistakes

- Использовать SELECT * в реальных отчётах — лучше явно перечислять нужные столбцы.
