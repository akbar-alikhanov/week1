title: "СУММЕСЛИ"
objectives:
  - "Суммировать по одному условию"
---

## Theory

`СУММЕСЛИ` складывает значения из диапазона суммирования только для строк, где диапазон условия соответствует критерию.

```excel
=СУММЕСЛИ(диапазон_условия; критерий; диапазон_суммирования)
```

## Example

```excel
=СУММЕСЛИ(B2:B5;"North";C2:C5)
```

Суммирует продажи только клиентов из региона North.

## Common mistakes

- Перепутать порядок диапазонов условия и суммирования.
