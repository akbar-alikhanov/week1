## Theory

`СЧЁТЕСЛИ` считает, сколько ячеек в диапазоне удовлетворяют критерию.

```excel
=СЧЁТЕСЛИ(диапазон; критерий)
```

## Example

```excel
=СЧЁТЕСЛИ(B2:B5;"North")
```

Вернёт количество клиентов из региона North.

## Common mistakes

- Забывать кавычки вокруг текстового критерия.
