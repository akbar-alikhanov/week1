## Theory

`ДАТА` строит значение даты из трёх чисел: года, месяца и дня. Полезна при сборке дат из отдельных столбцов.

```excel
=ДАТА(год; месяц; день)
```

## Example

```excel
=ДАТА(2026;3;15)
```

Вернёт дату 15.03.2026.

## Common mistakes

- Путать порядок аргументов — сначала год, затем месяц, затем день.
