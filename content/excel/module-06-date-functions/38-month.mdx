## Theory

`МЕСЯЦ` возвращает номер месяца (1–12) из значения даты.

```excel
=МЕСЯЦ(дата)
```

## Example

```excel
=МЕСЯЦ("15.03.2026")
```

Вернёт 3.

## Common mistakes

- Ожидать текстовое название месяца вместо числа — для этого нужна ТЕКСТ с форматом «ММММ».
