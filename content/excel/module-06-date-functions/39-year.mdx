## Theory

`ГОД` возвращает четырёхзначный год из значения даты.

```excel
=ГОД(дата)
```

## Example

```excel
=ГОД("15.03.2026")
```

Вернёт 2026.

## Common mistakes

- Забывать, что результат — число, а не текст, и его можно использовать в сравнениях.
