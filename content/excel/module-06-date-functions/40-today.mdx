## Theory

`СЕГОДНЯ` возвращает текущую дату (без времени) и не принимает аргументов. Значение обновляется при каждом пересчёте книги, поэтому функция считается «волатильной».

```excel
=СЕГОДНЯ()
```

## Example

```excel
=СЕГОДНЯ()-ДАТА(2026;1;1)
```

Считает, сколько дней прошло с начала 2026 года — результат меняется каждый день.

## Common mistakes

- Ожидать, что СЕГОДНЯ() «запомнит» дату — значение всегда обновляется при пересчёте.
