## Theory

Функция `ИЛИ` возвращает ИСТИНА, если **хотя бы одно** из переданных условий истинно.

```excel
=ИЛИ(условие1; условие2; ...)
```

## Example

```excel
=ИЛИ(120000>100000; 3>7)
```

Первое условие истинно → результат ИСТИНА, даже если второе ложно.

## Common mistakes

- Использовать ИЛИ, когда по смыслу нужно, чтобы выполнялись сразу все условия (тогда нужна И).
