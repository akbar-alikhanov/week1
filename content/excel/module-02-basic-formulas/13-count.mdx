## Theory

`СЧЁТ` считает количество ячеек в диапазоне, которые содержат **числа** (даты тоже считаются числами). Текст и пустые ячейки не учитываются.

```excel
=СЧЁТ(диапазон)
```

## Example

```excel
=СЧЁТ(B2:B5)
```

Если все четыре ячейки содержат числа, вернёт 4.

## Common mistakes

- Использовать СЧЁТ, когда нужно посчитать текстовые ячейки — для этого нужна СЧЁТЗ.
