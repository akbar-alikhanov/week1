## Theory

Функция `ЕСЛИОШИБКА` вычисляет формулу и, если та возвращает ошибку (#DIV/0!, #N/A и т.д.), возвращает запасное значение вместо самой ошибки.

```excel
=ЕСЛИОШИБКА(формула; значение_если_ошибка)
```

## Example

```excel
=ЕСЛИОШИБКА(B2/C2;"Нет данных")
```

Если C2 равен 0, обычная формула вернула бы #DIV/0!, а с ЕСЛИОШИБКА вернёт «Нет данных».

## Common mistakes

- Оборачивать в ЕСЛИОШИБКА всю таблицу «на всякий случай», скрывая реальные проблемы с данными.
- Забывать, что ЕСЛИОШИБКА скрывает саму причину ошибки, если не логировать её отдельно.
