## Theory

`СРЗНАЧ` считает среднее арифметическое чисел в диапазоне: сумму делит на количество числовых значений, игнорируя пустые ячейки и текст.

```excel
=СРЗНАЧ(диапазон)
```

## Example

```excel
=СРЗНАЧ(B2:B5)
```

Для значений 120000, 45000, 210000, 98000 вернёт 118250.

## Common mistakes

- Путать среднее с медианой (для медианы есть отдельная функция МЕДИАНА).
- Забывать, что пустые ячейки не считаются как 0 при усреднении.
