## Theory

`СЧЁТЗ` считает все непустые ячейки — числа, текст, даты, логические значения. В отличие от СЧЁТ, она не ограничивается только числами.

```excel
=СЧЁТЗ(диапазон)
```

## Example

Если A1:A3 содержит: 100, "Alpha", пусто — то `=СЧЁТЗ(A1:A3)` вернёт 2 (число и текст, пустая ячейка не считается).

## Common mistakes

- Путать СЧЁТЗ с СЧЁТ, когда в диапазоне есть текстовые значения, которые тоже нужно посчитать.
