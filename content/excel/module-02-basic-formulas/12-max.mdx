## Theory

`МАКС` возвращает наибольшее числовое значение из диапазона — зеркальная функция к МИН.

```excel
=МАКС(диапазон)
```

## Example

```excel
=МАКС(B2:B5)
```

Для 120000, 45000, 210000, 98000 вернёт 210000.

## Common mistakes

- Забывать, что МАКС игнорирует текст, поэтому текстовые «числа» не участвуют.
