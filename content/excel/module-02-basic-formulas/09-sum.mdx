## Theory

Функция `СУММ` складывает все числа в указанном диапазоне (или нескольких диапазонах), игнорируя текст и пустые ячейки.

Синтаксис:

```excel
=СУММ(диапазон1; [диапазон2]; ...)
```

## Example

```excel
=СУММ(B2:B5)
```

Складывает продажи всех клиентов из столбца B, строки 2–5.

## Common mistakes

- Забывать расширить диапазон при добавлении новых строк.
- Суммировать диапазон вместе с итоговой строкой, задваивая результат.
