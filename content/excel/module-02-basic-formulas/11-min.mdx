## Theory

`МИН` возвращает наименьшее числовое значение из диапазона.

```excel
=МИН(диапазон)
```

## Example

```excel
=МИН(B2:B5)
```

Для 120000, 45000, 210000, 98000 вернёт 45000.

## Common mistakes

- Путать МИН (минимум) с МИНЕСЛИ, которая учитывает условие.
