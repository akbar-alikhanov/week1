## Theory

Сводная таблица (Insert → PivotTable) агрегирует данные из исходной таблицы: перетаскивая поля в области «Строки», «Столбцы» и «Значения», можно за секунды получить суммы, средние или количества по любым срезам — без единой формулы.

## Example

Перетащив «Регион» в область строк, а «Продажи» — в область значений (с агрегацией «Сумма»), сводная таблица покажет суммарные продажи по каждому региону.

## Common mistakes

- Строить сводную таблицу на диапазоне с пустыми строками внутри — лучше использовать умную таблицу.
- Забывать обновить сводную таблицу (Refresh) после изменения исходных данных.
