## Theory

Сортировка переупорядочивает строки по значению одного или нескольких столбцов. Многоуровневая сортировка (Data → Sort) позволяет задать несколько ключей: сначала по региону, затем внутри региона — по выручке по убыванию.

## Example

Продажи: Alpha (120000), Beta (45000), Gamma (210000).

После сортировки по убыванию выручки порядок станет: Gamma, Alpha, Beta.

## Common mistakes

- Выделять только один столбец перед сортировкой — остальные данные «расклеятся» от своих строк.
- Забывать про заголовки при выборе диапазона для сортировки.
