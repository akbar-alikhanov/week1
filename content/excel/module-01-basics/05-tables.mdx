## Theory

«Умная таблица» (Insert → Table) превращает обычный диапазон в структурированный объект: у столбцов появляются заголовки с фильтрами, формулы автоматически копируются на новые строки, а диапазон можно ссылаться по имени вместо адресов ячеек.

## Example

Таблица с именем `SalesTable` и столбцом `Revenue` позволяет писать формулу:

```excel
=SUM(SalesTable[Revenue])
```

вместо `=SUM(B2:B500)`, и при добавлении новой строки диапазон обновится автоматически.

## Common mistakes

- Оставлять пустые строки/столбцы внутри диапазона перед превращением в таблицу.
- Не переименовывать таблицу, из-за чего в больших книгах сложно ориентироваться.
