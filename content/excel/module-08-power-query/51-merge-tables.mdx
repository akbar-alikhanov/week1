## Theory

**Merge** объединяет две таблицы по общему ключу «в ширину» (как JOIN в SQL). **Append** склеивает таблицы «в высоту», добавляя строки одной таблицы к другой с одинаковой структурой столбцов.

## Example

Merge таблиц «Заказы» и «Клиенты» по столбцу ClientID добавит к заказам данные о клиенте. Append объединит «Продажи за январь» и «Продажи за февраль» в одну таблицу.

## Common mistakes

- Использовать Append, когда нужно подтянуть данные по ключу (для этого нужен Merge).
