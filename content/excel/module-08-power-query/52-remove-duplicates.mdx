## Theory

Remove Duplicates (в Power Query или на вкладке Data) удаляет строки-дубликаты, оставляя только первое вхождение. Можно указать, по каким столбцам сравнивать строки на дублирование.

## Example

Если два заказа имеют одинаковый OrderID из-за ошибки выгрузки, Remove Duplicates по столбцу OrderID оставит только одну из этих строк.

## Common mistakes

- Удалять дубликаты по всем столбцам, когда на самом деле дубликатом считается совпадение только по ключевому полю.
