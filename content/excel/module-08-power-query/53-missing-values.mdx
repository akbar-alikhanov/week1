## Theory

Пропуски (пустые ячейки) искажают агрегаты и формулы. Стратегии работы с ними: заполнить значением по умолчанию, заполнить предыдущим известным значением (Fill Down), либо исключить строки с пропусками из анализа — выбор зависит от смысла данных.

## Example

В Power Query команда Fill → Down копирует последнее непустое значение вниз по пустым ячейкам столбца — удобно для «вложенных» заголовков в выгрузках.

## Common mistakes

- Автоматически заменять все пропуски нулями — для числовых показателей вроде цены это может исказить анализ.
