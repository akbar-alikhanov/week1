## Theory

Power Query позволяет трансформировать структуру данных: менять тип столбца (текст ↔ число ↔ дата), разбивать один столбец на несколько по разделителю, разворачивать/сворачивать таблицы (Pivot/Unpivot).

## Example

Split Column → By Delimiter разобьёт столбец «Имя Фамилия» на два отдельных столбца по пробелу — «Имя» и «Фамилия».

## Common mistakes

- Менять тип столбца до очистки данных — некорректные значения (пробелы, текст в числовом столбце) превратятся в ошибки.
