## Theory

`ДЛСТР` возвращает количество символов в тексте, включая пробелы.

```excel
=ДЛСТР(текст)
```

## Example

```excel
=ДЛСТР("Alpha")
```

Вернёт 5.

## Common mistakes

- Забывать, что пробелы в начале/конце строки тоже учитываются в длине.
