## Theory

`ПРАВСИМВ` — зеркальная функция к ЛЕВСИМВ: возвращает символы с правого края строки.

```excel
=ПРАВСИМВ(текст; число_знаков)
```

## Example

```excel
=ПРАВСИМВ("Отчёт.xlsx";5)
```

Вернёт «.xlsx».

## Common mistakes

- Забывать, что счёт идёт строго с конца, включая пробелы и знаки препинания.
