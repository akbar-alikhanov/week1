## Theory

`ЛЕВСИМВ` возвращает указанное количество символов, начиная с левого края строки.

```excel
=ЛЕВСИМВ(текст; число_знаков)
```

## Example

```excel
=ЛЕВСИМВ("Alpha Corp";5)
```

Вернёт «Alpha».

## Common mistakes

- Не учитывать пробелы при подсчёте нужного числа символов.
