## Theory

`СЦЕПИТЬ` (или оператор `&`) объединяет несколько текстовых значений в одну строку.

```excel
=СЦЕПИТЬ(текст1; текст2; ...)
```

## Example

```excel
=СЦЕПИТЬ(A2;" ";B2)
```

Если A2="Иван", B2="Иванов" — вернёт «Иван Иванов».

## Common mistakes

- Забывать добавить разделитель (пробел, запятую) между склеиваемыми значениями.
