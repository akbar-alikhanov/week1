## Theory

`ПСТР` возвращает подстроку заданной длины, начиная с указанной позиции внутри текста.

```excel
=ПСТР(текст; начальная_позиция; число_знаков)
```

## Example

```excel
=ПСТР("2026-03-15";6;2)
```

Начиная с 6-го символа, берёт 2 символа — «03» (месяц).

## Common mistakes

- Ошибаться в подсчёте начальной позиции — символы нумеруются с 1, а не с 0.
