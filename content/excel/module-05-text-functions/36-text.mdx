## Theory

`ТЕКСТ` превращает число в текстовую строку с указанным форматом отображения — полезно при склейке чисел с текстом.

```excel
=ТЕКСТ(значение; формат)
```

## Example

```excel
=ТЕКСТ(0.156;"0.0%")
```

Вернёт текст «15.6%».

## Common mistakes

- Пытаться использовать результат ТЕКСТ в дальнейших вычислениях — это уже текст, а не число.
