## Theory

`СЖПРОБЕЛЫ` убирает пробелы в начале и конце строки и схлопывает несколько подряд идущих пробелов внутри текста до одного.

```excel
=СЖПРОБЕЛЫ(текст)
```

## Example

```excel
=СЖПРОБЕЛЫ("  Alpha   Corp  ")
```

Вернёт «Alpha Corp» без лишних пробелов.

## Common mistakes

- Полагать, что СЖПРОБЕЛЫ удаляет ВСЕ пробелы — на самом деле только лишние.
