## Theory

`ПРОСМОТРX` (XLOOKUP) — современная функция поиска, объединяющая возможности ВПР, ГПР и ИНДЕКС+ПОИСКПОЗ: ищет в любом направлении и не требует, чтобы искомый столбец был первым.

```excel
=ПРОСМОТРX(искомое_значение; диапазон_поиска; диапазон_результата; [если_не_найдено])
```

## Example

```excel
=ПРОСМОТРX(103;A2:A4;C2:C4;"Не найдено")
```

Находит ID 103 в столбце A и возвращает соответствующую цену из столбца C.

## Common mistakes

- Не использовать четвёртый аргумент «если не найдено» и получать ошибку #N/A вместо понятного сообщения.
