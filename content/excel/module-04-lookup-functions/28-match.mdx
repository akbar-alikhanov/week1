## Theory

`ПОИСКПОЗ` возвращает не само значение, а его **позицию** (номер по порядку) в диапазоне. Часто используется вместе с ИНДЕКС для гибкого поиска в любом направлении.

```excel
=ПОИСКПОЗ(искомое_значение; диапазон; [тип_сопоставления])
```

## Example

```excel
=ИНДЕКС(C2:C4;ПОИСКПОЗ(103;A2:A4;0))
```

ПОИСКПОЗ находит позицию ID 103 (третья строка), а ИНДЕКС возвращает цену из этой строки.

## Common mistakes

- Забывать 0 в качестве типа сопоставления для точного поиска.
