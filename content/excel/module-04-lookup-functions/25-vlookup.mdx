## Theory

`ВПР` ищет значение в первом столбце диапазона и возвращает значение из указанного столбца той же строки.

```excel
=ВПР(искомое_значение; таблица; номер_столбца; [точное_совпадение])
```

Четвёртый аргумент ЛОЖЬ означает точное совпадение — почти всегда нужен именно он.

## Example

```excel
=ВПР(102;A2:C4;3;ЛОЖЬ)
```

Найдёт строку с ID 102 и вернёт значение из третьего столбца — цену монитора, 15000.

## Common mistakes

- Забывать ЛОЖЬ в последнем аргументе — тогда ВПР может вернуть неточное совпадение.
- Искать значение, которого нет левее столбца результата — ВПР ищет только в первом столбце диапазона.
