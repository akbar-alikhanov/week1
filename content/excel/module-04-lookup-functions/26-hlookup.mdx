## Theory

`ГПР` — горизонтальный аналог ВПР: ищет значение в первой строке диапазона и возвращает значение из указанной строки того же столбца.

```excel
=ГПР(искомое_значение; таблица; номер_строки; [точное_совпадение])
```

## Example

Если в первой строке диапазона — названия месяцев, а во второй — выручка, `=ГПР("Март";A1:D2;2;ЛОЖЬ)` вернёт выручку за март.

## Common mistakes

- Использовать ГПР для таблиц, где данные организованы по столбцам, а не по строкам — тогда нужен ВПР.
