## Theory

`ИНДЕКС` возвращает значение из диапазона по номеру строки и (опционально) столбца — в отличие от ВПР, она может искать в любую сторону.

```excel
=ИНДЕКС(диапазон; номер_строки; [номер_столбца])
```

## Example

```excel
=ИНДЕКС(B2:B4;2)
```

Вернёт значение из второй строки диапазона B2:B4, то есть B3.

## Common mistakes

- Путать номер строки внутри диапазона с абсолютным номером строки листа.
